Module Selection
Prototypes

Interactive prototypes for the personalised module selection hypothesis. For user testing — March 2026.

MVP 1 — Full personalisation
5 questions
Collects goal, activities, lifestyle, location, and exercise frequency. Produces a weighted recommendation with a personalised rationale.
Higher precision · More user input required
MVP 2 — Lightweight
2 questions
Collects activities and location only. Faster to complete. The recommendation screen communicates the reduced precision with an option to refine.
Lower precision · Faster to complete
Depending on feedback from user interviews, engineering estimates, and data readiness, one of these prototypes will be selected as the basis for the V1 build.
